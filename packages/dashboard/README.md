# @adonis-agora/config-dashboard

The console SPA for `@adonis-agora/config`: entries per app, environment and label, an editor for
values and vault references, version history, diffs, rollback and the audit trail. It is served by
the control plane (no separate deployment); the host injects its deployment config as a JSON data
block.

Part of the Agora ecosystem. Built with the shared Agora console kit.
